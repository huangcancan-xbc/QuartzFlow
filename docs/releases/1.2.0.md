# QuartzFlow 1.2.0｜明暗视觉精修与弹性分隔条

本次更新围绕阅读清晰度与侧栏交互进行优化：改善暗色模式的文字和色彩层次，统一文件列表交互，并新增可选的橡皮绳分隔条效果。

## 新增：弹性分隔条

- 左右侧栏分隔线可随拖动方向柔和弯曲，反向拖动平滑过渡，松手后带惯性回弹。
- 靠近上下端点时自动减弱弯曲、拉长过渡范围，缓和局部折角。
- 保留原有分隔线粗细和 Obsidian 的侧栏调整行为。
- 通过 **Style Settings → QuartzFlow → 界面与布局 → 弹性分隔条** 控制，默认开启，遵循系统的“减少动态效果”设置。

此效果需要额外启用配套插件 **QuartzFlow 弹性分隔条 1.0.2**，仅支持桌面端。主题本身仍可独立使用。

## 视觉与排版

- Style Settings 的设置名称和说明统一为中文，按颜色、字体、内容样式及界面布局细分。
- 暗色标题使用柔和灰色，增强蓝、黄、绿、红装饰的辨识度，兼顾清晰度与舒适感。
- 优化暗色正文和加粗文字的层次，让重点内容更容易辨认。
- 内外部链接默认使用 `#ca9b51` 并加粗，增大外链文字与跳转图标之间的间距。
- 调整正文标题的段前段后距离，改善标题与上下文的衔接。

## 文件列表与大纲

- 恢复亮色文件夹分组的鲜艳色彩，完善暗色模式的卡片、边框和图标配色。
- 修复嵌套文件行的交互区域未填满可用宽度的问题。
- 放慢长文件名的悬停滚动，并根据实际溢出宽度计算移动距离。
- 强化原生大纲当前标题的视觉强调，避免悬停或切换选中项时因字重变化造成换行和行高跳动。
- 增强暗色大纲层级色块，并收窄文件列表样式的作用范围，减少对大纲交互的干扰。

## 源码与验证

- 主题和配套插件源码统一收纳到 `src/`，插件位于 `src/plugins/elastic-dividers/`。
- README 补充主题与插件各自的安装路径、更新方式及检查脚本用途。
- `npm run check` 集成主题构建、静态审计和分隔条回归检查，覆盖换向、惯性回弹、端点曲率、刷新率、开关及清理逻辑。

## 安装与更新

最低支持 **Obsidian 1.12.0**。

**主题：** 下载本次发布附件中的 `theme.css` 和 `manifest.json`，覆盖到 `.obsidian/themes/QuartzFlow/`，然后切换一次主题或重新加载 Obsidian。

**可选的橡皮绳效果：** 下载 `quartzflow-elastic-dividers-1.0.2.zip`，将其中的 `quartzflow-elastic-dividers` 文件夹解压到 `.obsidian/plugins/`。启用 **Style Settings** 和 **QuartzFlow 弹性分隔条**，再确认对应开关已开启。更新已安装的插件后，停用并重新启用一次该插件。

主题附件中的 `manifest.json` 属于主题；压缩包内的 `manifest.json` 属于插件，安装时分别保留在各自目录中。GitHub 自动生成的 Source code 压缩包包含完整开发源码，不是主题或插件的直接安装包。
